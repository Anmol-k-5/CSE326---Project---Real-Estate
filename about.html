Frequently Asked Questions in Lab Viva

We partitioned the codebase into distinct functional layers: Anmol manages data schemas and search logic (js/properties-data.js, js/search-filter.js); Mukesh owns the UI layout and responsive design system (index.html, css/main.css); and Kunal develops interactive utilities and client-side forms (js/calculator.js, css/components.css).
We use the standard banking equation: EMI = [P × r × (1+r)^n] / [(1+r)^n - 1], where P is the net loan principal (Property Price minus Down Payment), r is the monthly interest rate (Annual Rate / 12 / 100), and n is total monthly installments (Tenure in Years × 12).
We use the HTML5 window.localStorage API. When a user clicks the heart icon on any property card, its unique ID is stored inside a JSON array under the key dreamnest_saved_favorites_v2, surviving page refreshes and browser restarts.
